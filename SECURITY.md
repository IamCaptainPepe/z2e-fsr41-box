# SECURITY

## Античит — главная опасность

OptiScaler подменяет DLL рендер-стека (`dxgi.dll`/`winmm.dll`/`version.dll`) и подгружает
чужие upscaler-библиотеки. Античиты это видят. **Не ставьте ни во что онлайн.**

`install` предупреждает и отказывает (без флага `--i-understand-anticheat`) для:

- Destiny, Valorant, Rainbow Six, Fortnite, Apex, PUBG, Tarkov, The Finals;
- любых папок `EasyAntiCheat`, `BattlEye`, `Vanguard` внутри папки игры.

Флаг предназначен **только** для одиночных игр, где античит-модуль лежит «на всякий случай».

## Прочее

- Скачиваем строго по GitHub Releases API из `versions.json` (User-Agent `z2e-fsr41-box`),
  пишем sha256 в `cache/manifest.json`. Fallback-URL — только при 403 API.
- Скрипты не требуют администратора, не пишут вне папки игры и кэша, не лезут в реестр.
- `uninstall` удаляет только файлы, перечисленные в `<game>\.z2e-state.json`.
- INT8-сборки FSR — сторонние пересборки, официально AMD для gfx1150 не поддерживаются.
  Доверяйте тем зеркалам, которым доверяете.
- Уязвимости обёртки: issue в репозитории. Не используйте issues для чужих бинарников —
  они в репозиториях авторов.
